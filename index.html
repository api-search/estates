API Estates

One company, many front doors. These are vendors whose API surface is scattered across dozens of separate provider profiles — a product line here, an acquisition there, a documentation portal that never mentions its siblings. Each estate page joins them on the x-parent each profile declares — followed all the way to the company that owns them today, so Webex and Splunk sit inside Cisco rather than beside it — and shows the footprint as an agent encounters it: nothing merged, nothing deduplicated, nothing tidied up first.

Estates are ranked by spread — the distance between a company's best-rated API surface and its weakest. A high spread means the experience an agent gets depends entirely on which door it walked through.
